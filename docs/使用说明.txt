NPKStudio 使用说明
==========================

这是用来查看和编辑 DNF（地下城与勇士）图片资源的工具。
可以打开 .NPK 资源包和里面的 .IMG 图片，逐帧浏览、替换素材、调整顺序、
导出 PNG / GIF，也能把一批 .IMG 重新打包成 .NPK。

免安装：双击 NPKStudio.exe 即可运行，电脑上不需要装任何环境。
窗口标题栏显示当前文件名和版本号。


【界面】
  左栏    条目列表（NPK 模式是包内的 .img，文件夹模式是磁盘上的 .img）
  中栏    画布，显示当前帧
  右栏    上半是帧缩略图，下半是「帧检查器」（选中帧的位置与尺寸）
  底部    播放控制条 + 状态栏

  Ctrl+Shift+1  折叠 / 展开左栏
  Ctrl+Shift+2  折叠 / 展开右栏
  双击左右分隔条  恢复默认栏宽（折叠状态下画布占满）


【打开文件】
  1. 拖 .NPK 或 .IMG 文件进窗口
  2. 拖一个文件夹进窗口（文件夹里是若干 .img）
  3. 工具栏「打开」选文件，或「打开文件夹」选目录

  文件夹模式：子文件夹 = 一个 NPK，里面放若干 .img。
  这种 .img 自身不记录"它在 NPK 里的路径"，界面上的路径只用于显示；
  打包时由资源清单补上真实路径（见【打包成 NPK】）。

  搜索框按文件名过滤，停止输入约 0.15 秒后生效。


【看图和缩放】
  Ctrl + 滚轮    以光标为中心缩放
  中键拖拽       平移画布
  双击画布       适配窗口
  右键画布       背景、适配窗口、实际大小、标尺、参考线等
  右下角         显示当前缩放比例

  缩放会停在"像素完美"的档位上，所以放大后像素边缘是硬的，不会发糊。


【背景（7 档）】
  「透明格 ▾」下拉，或右键画布：

    透明格       跟随主题的棋盘格
    亮格         固定亮色棋盘格，对比更强
    暗格         深灰棋盘格，适合看亮色发光体
    纯黑         看素材本来的颜色
    深灰 / 浅灰  检查抠图边缘有没有杂色
    绿幕         检查半透明、抗锯齿边缘

  背景与效果互不影响：选什么底，处理后透出的就是什么底。


【效果（2 档）】
  播放条右侧「效果 ▾」：

    原图        文件里的原始像素（黑底也在）
    线性减淡    把纯黑当透明，光效更亮，接近游戏内观感

  怎么选：在 PVF 的 .ani 里看这个 IMG 有没有标 [GRAPHIC EFFECT] LINEARDODGE。
  标了就选「线性减淡」，没标就保持「原图」。

  发布包 示例/ 里的样本含 effect_flame_burst 等特效贴图，可以直接对比两种效果。

  选择会按 IMG 记住，下次打开还是它。
  全局默认存在 %LOCALAPPDATA%\NPKStudio\graphic-effect.json。

  ★ 预览不影响任何文件：
      画布显示   = 处理后的副本
      导出 PNG   = 原始像素
      写回 .img  = 文件里的原始字节
      另存 NPK   = 原始数据


【播放动画】
  [首页][上一帧][播放/暂停][下一帧][末帧]  3 / 10  倍率[1× (8 fps) ▾]  [循环]

  空格      播放 / 暂停（光标在输入框里时不触发）
  ← →       上一帧 / 下一帧

  · 倍率 9 档：0.25× / 0.5× / 0.75× / 1× / 1.25× / 1.5× / 2× / 3× / 4×
    1× = 8 fps（125ms），每档右边标了实际 fps
  · 关掉「循环」后播到末帧自停；倍率是全局设置，会被记住
  · DNF 的 IMG 里没有"每帧时长"这个概念，节奏写在 PVF 的 .ani [DELAY] 段（毫秒）
    常见值：快攻约 60ms、常规 100~150ms、待机 180~200ms
    对照着调时用 fps 更直观，例如 150ms ≈ 0.8×

  H         隐藏 / 显示选中的帧（不影响文件，见下）


【帧检查器（右栏底部）】
  选中一帧后出现：

    X / Y          帧左上角在角色坐标系里的位置，可以为负
    宽 / 高        帧的像素尺寸，改完会按最近邻重采样并重新编码
    插入           在当前帧之后插入一张 1×1 全透明帧
    删除           删除选中帧（多选时全部删除）    Delete
    上移 / 下移    调整帧在 IMG 里的顺序
    帧域 / LINK    只读信息

  · 多选：Ctrl+点击、Shift+点击。多选时位置与尺寸不可改
  · 撤销 / 重做：Ctrl+Z / Ctrl+Y，栈深 50 步，工具栏两个箭头同步可用状态
  · 删除仍被 LINK 引用的帧时，第一个引用它的链接帧会接替像素，画面不变


【替换素材】
  工具栏「替换」（方块加笔的图标）→ 选 PNG / BMP / JPG
  → 直接替换当前选中的那一帧，并按该 IMG 的像素格式重新编码。
  一次替换一帧；要改多帧就逐帧替换。


【隐藏帧（调试动画用）】
  H 键，或右键帧列表：「隐藏选中帧」「显示选中帧」「全部显示」

  · 隐藏只影响预览和播放，不改变文件内容，导出和保存照旧
  · 隐藏的帧缩略图变暗，右下角出现一只划掉的眼睛，仍然可以选中编辑
  · 播放时自动跳过隐藏帧，方便看剩下的帧连不连贯
  · 帧计数显示成 2 / 8（隐 2）


【拖拽排序】
  在帧卡片上按住并拖动超过 4 像素即开始拖，松手落到蓝色指示线的位置。
  拖到列表上下边缘会自动滚动；Ctrl+Z 可以撤销这次移动。


【改了哪几帧（变更标记）】
  一屏几十个缩略图时，靠这些标记确认动过哪些帧：

    橙色描边      这一帧被改过
    橙色圆点      替换过素材
    绿色「新」    新插入的帧
    小箭头 ↕      顺序被移动过
    小方块        改过宽高或裁剪过

  列表头显示 18 / 18（改 4）。
  撤销后标记自动消失，保存后全部清空。
  选中的帧显示蓝色描边，标记的角标仍然保留。


【标尺 / 参考线 / 像素对齐】

  画布顶部与左侧各有一条标尺，鼠标在画布上移动时会出现十字辅助线。

  标尺读数有两套基准，右键画布「坐标基准」切换，状态栏右侧显示当前基准：

    图像坐标（默认）  0,0 = 画布左上角，图片左上角就是 0,0
                      多帧 IMG 下取整幅画布（联合包围盒）的左上角，
                      所以切帧时标尺不会跳
    角色坐标          0,0 = 角色坐标系原点，读数与帧检查器里的 X/Y 一致，
                      适合多帧对齐、和 PVF 里的坐标对照

  帧检查器里的 X/Y/宽/高 永远是角色坐标，不随标尺基准变化。

  操作：

    Ctrl+R              显示 / 隐藏标尺
    Ctrl+;              显示 / 隐藏参考线
    Ctrl+Shift+H        在视图中央添加一条水平参考线
    Ctrl+Shift+V        在视图中央添加一条垂直参考线
    从顶部标尺向下拖    拉出一条水平参考线
    从左侧标尺向右拖    拉出一条垂直参考线
    拖动已有的参考线    移动它
    拖回标尺区域松开    删除它
    右键「清除参考线」  一次清空

  鼠标移到标尺上时指针会变成上下 / 左右箭头，表示这里可以拖。
  已固定的参考线在边缘显示坐标标签，线挤在一起时标签会自动错开。
  右键「参考线坐标」可以关掉标签。

  参考线是 1 像素实线，鼠标十字线是 1 像素虚线，两者不会混。

  像素对齐（默认开启，右键画布「像素对齐」）：

    · 缩放只停在整数倍（200% / 300% / 400%…）或整数分之一（50% / 33% / 25%…）
    · 画面按最近邻绘制，像素边缘是硬的
    · 适配窗口也向下取档，宁可留一点边
    · 参考线拖动吸附到整像素

  关掉后回到自由缩放，画面可能出现插值发虚。


【导出】
  当前帧 PNG    工具栏图片图标，导出原始解码像素，不受效果影响
  批量 PNG      多选帧后点同一个按钮，选目录，
                命名 {IMG名}_{序号:D3}.png
  GIF           整段动画导出为 GIF，每帧 100ms、无限循环
  NPK           见下一节


【打包成 NPK】
  文件夹模式下点工具栏的包裹图标：

    1. 第一次会要求选一份资源清单（选完记住，以后不再问）
    2. 选输出路径，默认文件名等于文件夹名
    3. 完成后状态栏显示条目数与路径来源

  工具栏「资源清单」菜单里可以随时：

    设置资源清单…      换一份清单并记住
    用资源清单导出…    临时用另一份清单导出
    生成资源清单…      从装满 NPK 的目录反向生成清单
    清除已记住的资源清单

  关于资源清单：

    .img 文件自身不记录它在 NPK 里的路径，解包成文件夹后路径就丢了，
    只剩"文件夹名 + 文件名"。而 NPK 里每条记录都必须带完整路径，
    所以需要一份外部清单告诉工具"这个 .img 该放在哪个路径下"。

    清单是纯文本，每行一条：

        IMG: sprite/character/priest/effect/xxx.img

    三条获取途径，都不需要 PVF：

        1. 用现成的清单文件（例如 missing_img_details.txt）
        2. 界面「资源清单 → 生成资源清单…」，选一个装满 NPK 的目录
           （客户端 ImagePacks2，或自己以前打包好的输出目录）
        3. 命令行： NPKStudio.exe --scan-paths "<NPK目录>" --out "<清单.txt>"

    不要指望靠文件夹名猜路径：DNF 的目录名本身带下划线，
    像 character_common_aura_18_aradrestaunt 这样的文件夹名，
    猜成 .../aura/18/aradrestaunt 就错了，真实路径是 .../aura/18_aradrestaunt。
    工具仍会做推断兜底，但只要走到推断，状态栏会警告
    "N 条路径是按文件名推断的，游戏内可能不生效"，看到就说明该补清单了。


【命令行】
  批量打包：

    NPKStudio.exe --pack "<导出文件夹根目录>" ^
                  --manifest "<清单.txt>" ^
                  --out "<输出目录>" ^
                  --base "<客户端 ImagePacks2 目录>"

  生成清单：

    NPKStudio.exe --scan-paths "<NPK目录>" --out "<清单.txt>"

  --base 可选。指定后与客户端已有的同名 NPK 合并：同名条目替换，其余保留。
  不加 --base 只输出本次的条目，直接覆盖同名 NPK 会丢掉包里原有的其他条目。

【常见问题】

  Q: 第一帧打开是空的？
    DNF 有些 IMG 第 0 帧是 1×1 的占位帧，画布会把那一个像素放到最大，
    看起来像没加载。这是文件的真实内容，往下翻一帧就有画面。
    状态栏和帧列表会标出每帧尺寸，例如 #000 1×1。

  Q: 选了「线性减淡」，图变淡甚至看不见了？
    它的规则是"亮度即透明度"，DNF 很多特效贴图是实心黑底加发光层，
    黑底会被当透明，所以整体变淡。切回「原图」即可看原始画面。
    如果某帧超过 75% 的像素变透明，状态栏会提示一次。

  Q: 参考线怎么加？找不到入口。
    三条路：Ctrl+Shift+H / Ctrl+Shift+V；右键画布「添加水平/垂直参考线」；
    直接从顶部或左侧标尺往外拖。

  Q: 怎么知道当前是什么版本？
    窗口标题栏末尾就是版本号。

  Q: 改了东西但分不清改了哪几帧？
    看帧卡片上的橙色描边和角标，具体含义见【改了哪几帧】。

  Q: 忘了保存就关了？
    未保存时标题栏文件名后有橙色 ●，关窗会问「保存 / 不保存 / 取消」。


【出问题怎么排查】
  程序目录 log\ 下有 crash-时间戳.log。
  打包失败看输出目录的 pack-report.txt。
  某个 IMG 画布显示异常时，可以先导出当前帧 PNG 对比，
  看是数据问题还是显示问题。


【已知限制】
  · v1 / v2 格式完整支持
  · v4 / v5 / v6 可以打开和保存，但属于实验性支持，保存后建议进游戏确认；
    v5 写回会重新编码成 ARGB1555，文件体积可能变大
  · v7 / v8 / v9 无法解析，只能原样保存
  · 不支持 OGG 音频播放
  · 超过 80 帧的 IMG，只有前 80 帧显示缩略图（点选仍可查看与导出）
  · 效果只作用于画布，右侧缩略图始终显示原始数据
  · 隐藏状态、标尺与参考线开关不写入配置，每次启动恢复默认
  · 搜索停止输入后会重置一次列表滚动位置
